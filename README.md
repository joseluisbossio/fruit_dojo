# Fruit Dojo

Desde PowerShell, dentro de esta carpeta:

    flutter create . --platforms=android --org ar.abakos --project-name fruit_dojo
    flutter pub get
    flutter run                      # probar en celular conectado / emulador
    flutter build apk --release      # APK en build\app\outputs\flutter-apk\app-release.apk

Requiere Flutter 3.27 o superior (usa Color.withValues).
